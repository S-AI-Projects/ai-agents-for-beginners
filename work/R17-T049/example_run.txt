--- Cryptographic Boundary Statement ---
CRYPTOGRAPHIC BOUNDARY STATEMENT: A SHA-256 hash digest provides data integrity and tamper detection (confirming that bits have not changed since the digest was computed). HOWEVER, A HASH DIGEST ALONE IS NOT AN AUTHENTICATED DIGITAL SIGNATURE. A bare hash does not prove identity, origin authenticity, or non-repudiation because anyone who modifies a payload can easily recompute a valid SHA-256 hash over the forged payload. True non-repudiation requires asymmetric cryptography (such as Ed25519 or ECDSA), where an agent signs the canonical payload digest using a secure private key, allowing verifiers to authenticate the identity of the signer using the corresponding public key.
